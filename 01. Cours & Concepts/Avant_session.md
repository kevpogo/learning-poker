🧠 Réflexes Rapides – Exploit Micro MTT (1€ / 2€)

⸻

🎯 OBJECTIF

Avoir des décisions automatiques contre les profils faibles.

👉 En micro :
•	Moins réfléchir
•	Plus exploiter

⸻

🔥 RÈGLE ABSOLUE

❗ En micro, on ne bluff pas les fish.
❗ On value à fond.

⸻

🟥 PROFIL 1 — FISH PASSIF (call tout)

📌 Signes :
•	Limp souvent
•	Call beaucoup
•	Bet rarement

✅ Réflexes :
•	Value très cher (2/3 → pot → overbet)
•	Bluff = ❌
•	Thin value = ✅

💣 Phrase clé :

“S’il peut call, il va call”

⸻

🟧 PROFIL 2 — SPEWTARD (agressif débile)

📌 Signes :
•	Overbet
•	Shove bizarre
•	Bet sans logique

✅ Réflexes :
•	Bluff = ❌
•	Bluff catch = ✅
•	Trap = ✅

💣 Phrase clé :

“Laisse-le faire les erreurs”

⸻

🟩 PROFIL 3 — REG STANDARD

📌 Signes :
•	Sizings cohérents
•	Peu d’erreurs

✅ Réflexes :
•	Jeu standard (équilibré)
•	Bluff OK
•	Value OK

⸻

🔥 PRÉFLOP

🎯 Contre limp

✅ Réflexes :
•	Iso large
•	Iso cher (4x + 1bb / limper)

⸻

🎯 Contre open bizarre (4x+, pot…)

✅ Réflexes :
•	Souvent fish
•	Call plus loose
•	3-bet value +

⸻

🎯 Contre shove débile

✅ Réflexes :
•	Moins fold
•	Range élargie

💣 Phrase clé :

“Sizing débile = joueur faible”

⸻

🔥 POSTFLOP

🎯 Question UNIQUE

Est-ce que vilain peut fold ?

❌ NON → VALUE

✅ OUI → BLUFF possible

⸻

🎯 C-BET

Board dry :
•	Cbet small (1/3)

Multiway :
•	Bluff = ❌
•	Value = ✅

⸻

🎯 TURN / RIVER

Contre fish :
•	3 barrels value
•	Overbet possible

Bluff :
•	Très rare

⸻

🔥 ERREURS À ÉVITER

❌ Bluffer un calling station
❌ Underbet en value
❌ Respecter un fish
❌ Overfold vs gros sizing

⸻
